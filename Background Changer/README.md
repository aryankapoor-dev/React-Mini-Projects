# 🎨 Background Changer

An interactive React application that dynamically changes the webpage's background color using **React Hooks**. This project was built to practice state management, side effects, and real-time UI updates with a clean and simple interface.

## ✨ Features

* 🎨 Instantly switch between multiple background colors
* ⚛️ Built entirely with React Hooks
* ⚡ Real-time UI updates
* 🖱️ Interactive color selection
* 💻 Lightweight and beginner-friendly implementation

## 🚀 Getting Started

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm start
```

---

## 🎯 Learning Outcome

This project was created to deepen my understanding of React Hooks by combining **`useState`** for managing application state with **`useEffect`** for synchronizing changes to the browser's document object. It demonstrates how user interactions can trigger state updates that immediately reflect in the user interface.
