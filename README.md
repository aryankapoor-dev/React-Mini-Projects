## 📖 About

This repository is a growing collection of **React mini projects** created while learning and experimenting with React.

Each project focuses on a particular concept—from basic state management to Hooks and interactive UI behavior. The goal is to gain hands-on experience by building small, focused applications that reinforce React fundamentals.

---

## 🚀 Concepts Covered

* ⚛️ React Components
* 🪝 React Hooks
* 📦 `useState`
* 🎯 Event Handling
* ♻️ Reusable Components
* 🎨 Dynamic Styling
* 🧩 JSX
* 📱 Responsive UI
* 📂 Project Organization

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/aryankapoor-dev/React-Mini-Projects.git
```

Navigate into the project

```bash
cd React-Mini-Projects
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm start
```
