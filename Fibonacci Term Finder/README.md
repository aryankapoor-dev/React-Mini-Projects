# 🔢 Fibonacci Term Finder

An interactive React application that calculates the **nth Fibonacci number** using a recursive algorithm. This project was built to practice React state management while exploring recursion and dynamic rendering.

## ✨ Features

* 🔢 Find the nth Fibonacci number
* ⚡ Instant calculation as the input changes
* 🔄 Recursive Fibonacci implementation
* ⚛️ Built using React Hooks
* 💻 Clean and responsive interface

---

## 🚀 Getting Started

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm start
```

## 🎯 Learning Outcome

This project was created to strengthen my understanding of React state management while implementing the Fibonacci sequence using recursion. It demonstrates how user input can trigger real-time calculations and dynamically update the interface through React's rendering process.
